## Completed ✅

1. When an agent finishes a task, it shares a brief summary of what was carried out.✅
2. When the model is writing text to users, it renders properly instead of showing raw markdown.
3. User messages are rendered as plain text, not markdown.
4. A tiny copy button was added to the user input text, in case the user wants to copy the request.
5. Ability to select an aspect of the agent's output and add it to context to get more clarification.
6. A retry mechanism was added in the backend for errors coming from OpenRouter.
7. When a previous conversation is reopened, it no longer shows approval messages (Preview Diff / Apply / Reject) as still highlighted/active once the user has already made a choice.
8. The context token counter resets when the "+" (new chat) button is clicked.
9. Ability to rename a conversation in history, to aid recollection.
10. Ability to send all or specific problems highlighted in VS Code's Problems panel to the agent for resolution.
11. When the agent needs the user to apply or reject an edit, the option is no longer inside the body of the message — it's a persistent bar below the header / above the input field, with an "Apply All" / "Reject All" option when 3+ changes need acknowledgment.
12. No redo button — undo only.
13. When undo is clicked, the chat below that point is completely cleared from the user's view and from context.
14. After undo, the user's input field is auto-filled with the undone message so it's ready to edit and resend.
15. When the model writes a large code block, it's collapsed by default (crunched) to avoid excessive scrolling — showing just a snippet, with a summary visible since the full content is written to the file.
16. Model selector supports High / Medium / Low reasoning-effort selection.
17. Context refinement — the assistant resolves context and clarifies before acting, plans by default, searches efficiently, and verifies its own work.
